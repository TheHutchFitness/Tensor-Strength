The build proceeded through frontend install and compile; the actual terminal error is the `yarn build` type error above.

## Fix (to apply in the source environment)
In `app/page.tsx`, resolve the `EmailCapture` reference on line 33 — one of:
1. Add the missing import, e.g. `import EmailCapture from "@/components/EmailCapture";` (or the correct path/named-import matching where the component actually lives), **if** the component exists in the repo; or
2. If `EmailCapture` was renamed/removed, correct the JSX to the right component name; or
3. If it's not needed, remove the `<EmailCapture />` line.

Verify locally with `yarn build` (or `next build`) — it must compile and type-check clean — then re-trigger the deploy.
